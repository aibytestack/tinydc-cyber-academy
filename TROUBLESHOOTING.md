# Troubleshooting Guide - Tiny DC Cyber Academy

## Common Questions & Resolutions

### 1. The dev server doesn't respond or shows a blank screen
- Verify that `PORT=3000` is free.
- Run `npm run build` to confirm there are no syntax or type errors.
- Restart the dev server with `npm run dev`.

### 2. Unit tests fail to run
- Run tests using `npx --yes tsx --test src/utils/*.test.ts`.
- Ensure Node.js version is >= 20.x.

### 3. AI Tutor returns local knowledge responses
- The tutor uses the built-in deterministic knowledge engine.
- It does not require an external AI API key or cloud connection.
- Its responses are rule-based rather than generated by a large language model.

### 4. Progress reset or export questions
- Navigate to **System Settings** in the left sidebar or click the gear icon in the top navbar.
- Click **Export Progress Backup (.json)** to save your profile.
- You can restore your progress anytime by pasting the backup JSON into the import field.
